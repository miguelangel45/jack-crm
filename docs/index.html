Sobre el proyecto

Construido para evolucionar.

CRM Operativo está desarrollado con Next.js, TypeScript y Tailwind CSS. Su aplicación incluye autenticación, rutas API y una base para integraciones con servicios externos.

Acerca de esta publicación

Esta página presenta el proyecto. El acceso al CRM y las integraciones necesitan un servidor y no están disponibles en GitHub Pages.
